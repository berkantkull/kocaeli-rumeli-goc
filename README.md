# Koca-ili Türkmenlerinin Rumeli'ye Göçü

Kocaeli sancağındaki köylerle aynı adı taşıyan Rumeli köylerini gösteren etkileşimli harita.

**Harita:** https://berkantkull.github.io/kocaeli-rumeli-goc/

## Kaynak

Hacer Ateş, "Koca-ili Türkmenlerinin Rumeli'nin İskânına Katkıları",
*Osmanlı Araştırmaları / The Journal of Ottoman Studies*, LXII (2023), s. 1-46.
DOI: [10.18589/oa.1398363](https://doi.org/10.18589/oa.1398363)

Haritadaki veriler makaledeki Tablo I–IV'ten aktarılmıştır:

| Tablo | Dönem | Bölge |
|---|---|---|
| I | Süleyman Paşa | Gelibolu ve çevresi |
| II | I. Murad | Paşa Livası (sağ kol) |
| III | I. Murad | Vize Sancağı |
| IV | I. Murad | Çirmen Sancağı |
